## 量化交易的本质与研究流程

量化交易可以理解为：用可检验的规则，在不确定性中承担有回报的风险，争取扣除成本后的
长期收益。单次交易结果具有不确定性，能够研究和管理的是决策过程、收益分布及其适用条件。

| 核心问题 | 需要弄清的内容 |
| --- | --- |
| 收益从哪里来 | 可能来自风险补偿、提供流动性、信息处理优势或参与者的行为差异；这些来源需要具体论证 |
| 优势是否真实 | 观察到的关系是否经得住未来信息泄漏、过拟合、选择偏差和后续样本的检验 |
| 优势能否兑现 | 预测如何转成实际仓位和成交，成本、市场冲击及容量是否消耗了预期收益 |
| 能否承受判断错误 | 仓位、相关性、杠杆和尾部损失是否使资本能够承受不利路径 |

讨论中使用的研究与实践流程是：

```text
提出具体假设 → 设计实验并验证证据 → 配置风险 → 执行交易 → 根据新证据修正判断
```

证据不足或反驳假设时，可以停止或修改研究主张，并不自动进入交易。预测误差改善、相对
基线具有收益优势、扣除成本后可实现收益，是不同层面的证据；其中一层成立不能替代其他层。

收益来源也可能包含承担风险所获得的补偿。正收益本身不等于存在错误定价，额外收益相对
哪个风险基准成立，需要在具体研究中另行定义。

## 收益来源、特征与简单规则的关系

收益来源表达可能的获利机制，特征表达当时可观察的信息，规则或模型表达如何把这些信息
映射为预测或行动。可以用一个尚未验证的趋势例子拆开这些层次：

| 层次 | 示例 |
| --- | --- |
| 经济机制假设 | 市场参与者逐步消化信息，价格调整可能持续一段时间 |
| 可检验的预测主张 | 过去表现较强的股票，在随后一段时期仍相对较强 |
| 可观测事实与特征 | 当时已知的历史价格，以及由其计算的过去20日收益率 |
| 规则或模型 | 用历史收益率及其他输入预测未来收益、方向或相对排名 |
| 决策与执行 | 结合风险约束决定是否参与及投入多少资本，再按可实现条件交易 |

同一个过去20日收益率，也可以用于提出“上涨过快后可能回落”的假设。因此，选定特征并不
自动选定关系方向，更不自动解释收益成因。一个特征还可能因为表达风险而具有预测能力。

简单规则同样是模型，包含对观察事实的解释和行动假设。这种理解可能错误，需要独立证据。
经济解释可以帮助构造特征、预期失效条件，但监督学习研究也可以先检验具体的统计预测关系；
不必先确认一个完整的经济因果故事。

## 回测提供什么证据

回测是在明确的历史数据和模拟条件下，估算“假如当时运行这套策略，会发生什么”。基本过程
是在每个历史时点只提供当时可得的信息，执行事先定义的决策与更新规则，再按成交、资金和
成本假设计算结果。

历史行情是已观察到的输入，策略行为及其成交是模拟结果。回测是否可信取决于这些输入与
假设是否适合所研究的问题；它不是对当时真实策略交易结果的直接观察。

“优势是否真实”至少涉及三个不同环节：

1. 回放是否可信：历史信息的可见时点、股票池、公司行为、成交和成本是否处理正确。
2. 结果是否来自选择：试验了多少规则、特征和参数，失败结果是否参与了最终选择。
3. 后续表现是否支持：冻结方案或更新规则后，在未参与选择的数据中是否仍有改善。

历史数据既可以用于提出假设，也可以用于选择模型，但同一份结果一旦影响了设计，就不能
继续被当作完全独立的最终验证证据。反复查看所谓样本外结果并据此修改方案，也会产生选择
问题。回测过拟合的讨论见
[The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。

盈利回测提供特定模拟条件下的历史表现证据，不单独证明经济机制或未来收益。纯预测研究
可以先评价按时间顺序得到的样本外预测，无需先构建完整交易回测。

## 监督学习建模与验证

在监督学习的收益预测例子中，`Xₜ` 是预测时点可见的特征，`Yₜ` 是之后才观察完整的目标，
`fθ` 将输入映射为预测：

$$
\widehat{Y}_t=f_\theta(X_t).
$$

选择目标，决定研究的是收益幅度、上涨概率、相对排名或其他对象；选择特征、模型及训练
方式，决定尝试从哪些信息中学习何种关系。模型可以通过训练确定关系的方向、强度和交互，
但这些选择以及比较基线仍需要研究者明确。

| 环节 | 作用 | 证据边界 |
| --- | --- | --- |
| 训练 | 在候选函数中估计参数、形成预测器 | 训练集拟合良好不自动说明泛化有效 |
| 模型选择 | 使用选择数据比较特征、方法、超参数或更新规则 | 选择过程使用过的数据已参与研究决策 |
| 最终验证 | 在未参与设计和选择的数据上，评价已确定的方案或更新规则 | 结论受验证范围、不确定性和市场变化限制 |

金融时间序列的相邻样本、重叠标签和共同市场冲击可能相关，未来分布也可能变化。不能在
没有核对条件时，直接把独立同分布样本下的学习保证当作未来市场表现保证。

## 三个不同层次的“假设”

| 层次 | 含义 | 示例 |
| --- | --- | --- |
| 一般研究期待 | 认为当前任务可能存在能够学到并泛化的预测关系 | 当前可得信息可能改善未来收益预测 |
| 具体研究假设 | 本轮研究准备支持或否定的明确主张 | 增加跌停状态后，指定模型的未来5日收益预测误差降低 |
| 机器学习的 hypothesis | 候选预测函数；所有允许选择的函数构成假设空间 | `ŷ = fθ(x)`，例如一个参数已确定的线性预测器 |

“存在能够学习并泛化的关系”太宽泛，不能单独指导某一轮实验；监督学习理论也不保证任意
金融数据都包含相对既定基线有用的信号。原先讨论的“提出假设 → 验证证据”中的假设，指
第二行的具体研究主张。学习理论中函数与假设空间的含义见
[Understanding Machine Learning](https://www.cs.huji.ac.il/~shais/UnderstandingMachineLearning/understanding-machine-learning-theory-algorithms.pdf)。

研究假设决定要验证什么，实验设计决定怎样验证。不同假设可以使用相同数据和模型；同一个
假设也可以用不同实验检验。一项研究可以包含多条相关主张，但每条主张的证据需要分别判断。

例如，“过去收益包含后续收益的信息”和“相同输入下树模型优于线性模型”可以使用相同
数据，但研究内容不同：前者讨论信息或市场关系，后者讨论学习方法。新增公告文本没有改善，
也可以与已有价格信息具有预测能力同时成立。

论文中研究的正是这些具体主张。例如，Jegadeesh 与 Titman 的动量论文考察过去表现较强
股票在随后数月的相对表现，属于具体收益关系研究。其结果绑定所研究的样本与方法，不能
扩展成任意时期、任意市场的保证，见
[Returns to Buying Winners and Selling Losers](https://onlinelibrary.wiley.com/doi/10.1111/j.1540-6261.1993.tb04702.x)。

## 五类具体研究假设

下面是按“待验证的主张”整理的工作分类，不是唯一标准，类别可以交叉。

| 类别 | 核心主张 | 待验证示例 | 主要证据 |
| --- | --- | --- | --- |
| 信息增量 | 一类输入对目标包含既有信息之外的预测价值 | 公告文本在价格与财务信息之外改善未来收益预测 | 可比学习条件下的增量预测评价，并核对信息是否确实新增 |
| 关系结构 | 输入与目标之间存在特定方向、形态或交互 | 跌停后的5日平均收益为正；该关系随流动性变化 | 对应统计量、关系约束或交互的检验，以及后续样本验证 |
| 经济机制 | 某种行为、约束或风险产生了观察到的关系 | 临时被动卖出造成价格压力，压力消退后价格回升 | 能区分竞争解释的机制证据；因果主张需要相应识别依据 |
| 学习方法 | 某种表征、模型或训练方法更有效地提取信息 | 相同输入下，树模型优于线性模型 | 相同任务、信息、验证数据和可比调参预算下的方法比较 |
| 适用边界 | 关系在某些时期、市场或状态下成立、变化或失效 | 早期发现的关系在之后未参与研究的年份仍成立 | 预先明确范围的外部验证及效果差异评价 |

实际论文可能横跨多类。例如，Gu、Kelly 与 Xiu 比较学习方法并分析非线性交互带来的预测
改善，可以从学习方法和关系结构两个角度理解；这不意味着某种复杂模型在所有市场都更好。
见 [Empirical Asset Pricing via Machine Learning](https://www.nber.org/papers/w25398)。

同样，研究动量风险与市场状态的关系可以涉及结构和适用边界；通过投资者信念形成模型解释
反应不足与过度反应则涉及经济机制。参见
[Momentum Crashes](https://www.nber.org/papers/w20439) 和
[A Model of Investor Sentiment](https://www.nber.org/papers/w5926)。这些论文不构成本例
“跌停后5日反弹”的直接证据。

## 待澄清问题与未来想法：跌停后5日反弹

### 1. 先固定事件、特征、目标和主张

“当日是否跌停”是特征；“跌停后5日会有反弹”已经包含对未来收益的关系假设。
为了比较五类研究，以下统一使用这些示例口径：

| 对象 | 本例的约定 |
| --- | --- |
| 样本 | 某个事先明确的股票池中的股票日，股票与日期范围尚未选定 |
| 信息截止时点 | 交易日 `t` 收盘之后；具体发布时间和可用延迟在实验前确定 |
| 特征 `Dₜ` | 当日收盘处于当日实际适用的跌停价为1，否则为0；这里讨论收盘跌停 |
| 目标 `Yₜ` | 从 `t` 日收盘到之后第5个交易日收盘的累计收益 |
| 原句的统计版本 | 在跌停事件组中，`Yₜ` 的条件均值大于0 |

可将原句的统计版本写为：

$$
\mathbb{E}[Y_t \mid D_t=1] > 0.
$$

这里的5日收益是预测标签，不预设能够按 `t` 日收盘价成交。“第5日当天上涨”“未来5日内
至少一次高于起点”“从区间最低点反弹”是其他标签，不与本例混用。

跌停状态按每只股票在对应日期适用的规则和原始价格识别。涨跌幅限制会随制度变化，不能把
今天的规则或一个固定跌幅套用到全部历史。相关制度变化可见
[上交所2026年交易规则修订说明](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20260424_10816474.shtml)。
该资料只说明规则需要按历史时点核对，不提供本例的收益证据。

实际实验前还需明确交易日历、无涨跌幅限制日、分红拆股、停牌、退市与缺失终点价格的处理。
收益采用一致的价格调整或总收益口径；这些选择不能根据结果好坏事后改变。示例没有预设这些
尚未讨论的正式数据规则。

### 2. 信息增量：跌停状态改善现有预测

具体主张可以写成：

> 在既有输入之外，增加当日跌停状态，能够降低未来5日收益的样本外预测误差。

设置两套输入：基线使用既有特征 `Xₜ`，实验组使用 `Xₜ` 与 `Dₜ`。固定预测目标、样本、模型
族、验证数据和评价口径，使用可比的调参与训练条件，比较未参与选模的数据上的损失差异。
均方误差可以作为示例指标；具体指标及有意义的改善幅度需要在实验前确定。

样本应同时包含跌停和未跌停的股票日。如果只保留跌停事件，`Dₜ` 始终为1，无法检验该特征
在两组之间的区分能力；此时可以检验事件组自身的收益关系或其他条件变量。

这个假设不要求预测方向为上涨。假如增加跌停状态后更准确地预测了后续下跌，预测增量可能
得到支持，原句中的反弹关系却没有因此得到支持。

#### 新信息与显式表征的区别

如果既有输入已经包含收盘价、当日跌停价及构造 `Dₜ` 所需的全部信息，那么存在确定函数：

$$
D_t=g(X_t).
$$

此时增加 `Dₜ` 没有增加原始信息。有限样本、有限表达能力或特定训练方式的模型仍可能因此
预测得更好，但更直接的解释是显式表达帮助了学习，属于学习方法或表征的有效性问题。

反过来，如果既有输入尚不包含这项事实，加入它后预测改善可以支持所测试方案中的增量价值。
某个学习器没有改善，也不能单独证明所有方法都无法从该信息中获益。

### 3. 关系结构：跌停之后的收益具有特定方向或形态

最直接的主张就是前述条件均值大于0。可以估计事件组的5日平均收益及其不确定性，再在未
参与发现该规律的后续数据中验证。仅观察到正的样本均值，还需要考虑样本量、相关性和选择
过程，才能判断证据强度。

以下三个主张应分别处理：

| 主张 | 对应统计对象 |
| --- | --- |
| 跌停后平均反弹 | `E[Yₜ ∣ Dₜ = 1] > 0` |
| 跌停后多数情况下反弹 | `P(Yₜ > 0 ∣ Dₜ = 1) > 0.5` |
| 跌停后表现高于基线预期 | 事件组收益相对预先指定基线的差异 |

正的平均收益可能来自少数较大的上涨，不能直接推出多数事件上涨。正的绝对收益也不自动
构成正的相对收益。例如，构造一个事件组平均上涨1%、比较基线预期上涨2%的例子，就能看到
这两条主张的区别；这两个数字没有对应实际实验。

若提出“跌停后收益相对行业基准为正”，应事先定义行业基准及其使用方式。这是另一条关系
主张，基准也不能在看到结果之后选择。

还可以增加结构主张：

> 跌停后的5日收益关系受到当时流动性状态的影响。

此时需要估计状态之间的效果差异，或比较允许与限制相应交互的模型。控制其他输入后的
预测关系仍是关联证据，不自动成为经济机制的证明。

### 4. 经济机制：临时卖出压力造成后续反弹

可以提出这样的机制假设：

> 一部分跌停由临时被动卖出造成；卖出压力消退后，价格回升。

它增加了“为什么发生”的主张。仅有收盘价和5日收益，通常不足以区分临时卖压、基本面变化、
市场整体反弹等解释。可以进一步研究：

- 是否存在与被动卖出相对应的资金流或订单压力证据；
- 压力变化与价格恢复的时间关系是否符合机制推论；
- 在具有可比背景的事件中，该机制能否解释额外的差异；
- 能否找到有充分依据的外生变化，并明确排除其他解释所依赖的条件。

订单失衡、公告分类或资金流指标都可能只是代理变量，不能直接等同于“恐慌”“非理性”或
被动卖出。机制研究中后来取得的证据，也不能倒填为预测时点已经可见的模型输入。

跌停特征具有预测价值、模型将其评为重要，或事件后确实出现上涨，都不能单独确认这个原因。
因果推断需要额外的模型与识别假设，参见
[Causality for Machine Learning](https://arxiv.org/abs/1911.10500)。

### 5. 学习方法：某种方法更好地利用跌停相关输入

可以提出一个方法比较假设：

> 在相同的跌停、波动率和流动性输入下，树模型对未来5日收益的样本外预测优于线性模型。

固定目标、信息、数据切分、评价指标和可比调参预算。若特别关心跌停事件组的误差，应在
实验前明确事件组指标与全样本指标各自的用途，不能事后选择对某个模型有利的评价集合。

可以组织四组对照：

| 学习方法 | 不含显式跌停特征 | 含显式跌停特征 |
| --- | --- | --- |
| 线性模型 | A | B |
| 树模型 | C | D |

- B 与 A、D 与 C 的差异，分别说明显式加入该特征对两种方法的影响。
- C 与 A、D 与 B 的差异，比较相同输入下的方法表现。
- D 优于 B，不足以确认改善来自跌停特征；它也可能来自对其他输入的更好利用。

如果进一步主张“树模型的优势来自跌停与流动性的交互”，就增加了关系结构的解释，需要
针对该交互的对照证据。四组比较有助于定位差异，但不自动证明真实的数据生成机制。

如果唯一输入是二元变量 `Dₜ`，对于条件均值预测，带截距的线性模型已经能够分别表示两组
均值：`E[Yₜ | Dₜ = 0]` 和 `E[Yₜ | Dₜ = 1]`。单凭这一个二元输入，没有额外的复杂交互
结构可供更复杂的模型表达；实际学习表现仍可能受估计和正则化方式影响。

### 6. 适用边界：关系在新时期或其他制度下如何表现

可以分别提出：

> 早期样本中发现的跌停后5日反弹关系，在之后未参与研究的年份仍然成立。

> 跌停后的5日收益关系，在不同涨跌幅限制制度下存在差异。

预先定义时期、股票范围或制度条件，保持事件、收益与统计口径可比，再检查效果及其不确定性。
若跨制度比较不得不改变定义，应把变化明确列入研究主张，不能把不一致的标签混为同一实验。

一个时期显著、另一个时期不显著，不足以证明两时期的效果不同；还应检查效果差值及其
不确定性。类似地，若状态分组用于实时预测，状态必须能由预测时点的信息定义，不能使用
事后划出的牛熊市或事后识别的最低点作为当时输入。

“用最近两年训练比全部历史更好”直接属于学习方法比较；“改善源于市场关系发生漂移”又
增加了对时间适用性的解释。方法胜出本身不足以确认这个原因。

尝试许多市场、年份、分组和持有期后挑选最优结果，会使发现与最终验证混在一起。研究选择
过程与回测过拟合的关系见
[The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。

## 将示例变成实际研究前需要确定的内容

下列内容是本例尚未确定的实验输入，不构成新的研究治理要求；记录、Acceptance、证据保存
和采用决定仍遵循前述 Research 工作流。

1. 明确本次只检验哪一条主张，以及与哪一个基线比较。
2. 确定股票池、时期、数据来源、历史可见版本、预测截止时点和5个交易日的定义。
3. 确定事件与收益口径、停牌和退市等情况的处理，并说明连续跌停按股票日还是按事件段计数。
4. 明确已有信息是否能够推导跌停状态，以区分原始信息增量和显式表征的作用。
5. 确定候选范围、训练与选择数据、独立最终验证数据、指标、通过条件和停止条件。
6. 确定如何处理相关样本、不确定性和多次尝试，并保留影响判断的失败结果。

训练样本的5日标签需要在训练时点之前已经完整可见；特征预处理、筛选和调参也不能利用
最终验证数据。连续跌停及重叠的5日窗口会产生相关观测；同一天多只股票还可能受到共同冲击。
不确定性估计需要适应这些依赖，不能简单把所有股票日当作独立样本。金融面板中的相关性问题
可参见 [Estimating Standard Errors in Finance Panel Data Sets](https://www.nber.org/papers/w11280)。

这些主张之间不存在自动推导关系。可能观察到“跌停状态改善预测，但后续平均收益为负”；
也可能观察到“事件组平均收益为正，但相对基线没有增量”。方法更好不自动确认经济机制，
一个时期的证据也不自动覆盖其他时期。任何实际结论都需要绑定对应主张、数据范围、实验版本
及验证结果。
